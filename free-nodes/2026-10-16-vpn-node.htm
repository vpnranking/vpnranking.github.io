步骤一：精准搜索 打开你的 iPhone 或 iPad，进入 App Store。在搜索栏中输入“Shadowrocket”。你会看到搜索结果中出现一个以灰色火箭为图标的应用。这里的关键点在于核对开发者名称。请务必确认开发者显示为“Yang Zhuo”，而非其他任何个人或公司。在如今山寨应用横行的时代，这一步是区分正版与高仿的黄金法则。

第二章：初识界面——拨开迷雾，看清每一寸布局

第三章：核心实操——从空白到“起飞”的配置全流程

这是本文的重头戏。很多人卡在第一步，不知道如何将手中的“订阅链接”或“服务器信息”填入应用。我们将分两种最常见的场景进行讲解。

场景A：使用“订阅链接”一键导入（最推荐）

这是目前市面上绝大多数机场（代理服务商）提供的方式。你只需向服务商购买套餐后，在用户中心获取一个以 https:// 开头的订阅地址。

  1. 复制链接：在浏览器或剪贴板中复制该订阅链接。
  2. 打开 Shadowrocket：进入“配置”页面。此时，应用通常会智能检测到剪贴板中的链接，并在顶部弹出一条提示：“检测到订阅链接，是否添加？”点击“添加”。
  3. 手动添加（无弹窗时）：如果没有弹窗，请点击配置页面右上角的“+”号，选择“类型”为“Subscribe”（订阅），然后在“URL”栏中粘贴刚才复制的链接。备注栏可以随意填写，例如“我的机场”。
  4. 完成下载：点击“保存”后，应用会自动从服务器拉取节点列表。稍等片刻，你会在配置页面看到该订阅名称，点击它，即可查看下方展开的众多服务器节点。

场景B：手动添加单个服务器节点

如果你拥有的是某台特定服务器的 IP、端口、密码和协议，而非订阅链接，则可以手动添加。

  1. 在“配置”页面，点击右上角的“+”号。
  2. 在“类型”一栏中，选择你的服务器协议。Shadowrocket 支持极其丰富，包括最常用的 SS（Shadowsocks）、SSR、V2Ray（VMess）、Trojan 等。请务必与你的服务商提供的信息保持一致。
  3. 依次填写“地址”（服务器 IP 或域名）、“端口”、“密码”。如果是 V2Ray 协议，还需要填写“用户 ID”（UUID）和“alterId”。对于高级用户，还可以配置“传输方式”（如 ws、tls 等）。
  4. 填写完毕后，点击右上角“保存”。该节点便会出现在配置列表中。

启用代理：一触即发

无论是通过订阅还是手动添加，节点列表已经就绪。现在，回到“首页”状态页。在“节点”一栏中，点击当前显示“选择节点”的区域，从弹出的列表中选择一个你想要的服务器（建议优先选择延迟低、标有“可用”的节点）。然后，将首页中央的开关拨动至“打开”状态。

此时，系统会弹出“Shadowrocket 想要添加 VPN 配置”的对话框，点击“允许”并验证密码。随后，状态页的开关变为绿色，顶部状态栏会出现一个“VPN”图标。恭喜你，此刻你已经成功“起飞”，可以畅游网络了。

第四章：进阶技巧——让“小火箭”更懂你的心思

仅仅能连接还不够，Shadowrocket 的强大之处在于其分流规则。默认情况下，它会将所有流量都通过代理发送，这可能导致访问国内网站速度变慢。通过配置规则，我们可以实现“国内直连，国外代理”的智能分流。

  1. 开启分流：进入“配置”页面，点击你正在使用的配置（例如“Default”），选择“编辑” -> “规则”。
  2. 理解规则逻辑：规则列表从上到下依次匹配。每条规则包含“类型”（如 DOMAIN-SUFFIX 域名后缀、IP-CIDR IP段）、“条件”和“策略”（如 Proxy 代理、DIRECT 直连、REJECT 拒绝）。
  3. 使用现成模板：对于新手，不建议手动编写规则。你可以删除默认规则，然后在“配置”页面下拉，从“远程资源”中引用网上大神们维护好的“懒人规则”（例如国内直连规则集）。点击右上角的“+”号，选择“类型”为“URL”，粘贴规则链接并保存。这样，应用就会自动下载并更新这些规则，实现智能分流。

此外，在“设置”中，强烈建议开启 “按需连接” 和 “开机启动”。这样，只要你的设备连接 Wi-Fi 或蜂窝数据，小火箭就会自动在后台建立安全连接，无需每次手动开启，真正做到无感防护。

FAQ

Netch 全局代理与规则代理的区别是什么？
全局代理会将所有流量通过节点转发，适合游戏或全局科学上网；规则代理只针对指定应用或 IP 走节点，优化带宽利用和网络效率，根据不同需求选择使用模式。
SSR 的端口转发功能如何开启？
在服务器端配置文件中启用 port_forwarding 参数并指定目标端口与地址。确保防火墙开放转发端口，客户端使用对应端口连接即可实现流量中继。此功能常用于内网穿透或端口复用。
Potatso Lite 能否兼容最新的 iOS 系统？
Potatso Lite 更新频率较低，在新版本 iOS 上可能出现兼容性问题。若遇到无法连接或闪退情况，建议升级至其他活跃维护的客户端如 Shadowrocket 或 Quantumult X。
如何在 Sing-box 中设置多个 outbound 实现策略路由？
在 sing-box 的配置中定义多个 outbound 对象并为 routing 模块配置 rules，将不同目的地或应用流量指向对应 outbound，从而实现分流、负载均衡或故障转移等复杂路由策略。
V2Ray 配置中如何避免端口扫描暴露服务？
避免使用常见端口（如 80、443）直接暴露 V2Ray 服务；若必须使用 443，建议通过 Web 服务器反代或使用 CDN；同时启用 fail2ban 与 iptables 限制异常连接频率，减少被扫描发现的风险。
Nekobox 如何管理多协议节点和分流？
Nekobox 可同时管理 Shadowsocks、VMess、Trojan 等多协议节点。结合策略组和分流规则，可实现不同流量走不同节点，提升网络效率和管理便利性。
Mihomo 节点分组如何自动切换？
用户可按延迟、地区或用途将节点分组，并启用策略组。系统会根据节点健康状况和延迟自动切换到最佳节点，保证网页浏览、视频播放和游戏连接稳定顺畅。
VMess 协议的动态端口功能是什么？
VMess 支持动态端口（port hopping）功能，能在一定范围内自动变更通信端口。此机制可有效防止防火墙基于端口的封锁策略，提高节点长期稳定性。
何时应选择 VLess 而非 Vmess？
若追求更轻量、高性能的连接且采用外部 TLS 或 XTLS 进行加密，建议选择 VLess。VLess 去除了内嵌加密，能更好配合现代传输（XTLS/Reality）实现更低延迟与更好扩展性。
SSR 的 UDP 转发功能需要注意什么？
SSR 的 UDP 转发需要服务端和客户端同时开启，同时确保服务器防火墙允许 UDP 通信。UDP 流量不可靠，可能在高丢包网络中导致连接中断，需要测试稳定性。
